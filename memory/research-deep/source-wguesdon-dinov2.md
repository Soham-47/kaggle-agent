# RSNA Knee DINOv2 at meniscus resolution

- ref: https://www.kaggle.com/code/wguesdon/rsna-knee-dinov2-at-meniscus-resolution (`wguesdon/rsna-knee-dinov2-at-meniscus-resolution`). Cached source: `competitions/rsna_knee/research-cache/rsna-knee-dinov2-at-meniscus-resolution.ipynb` (same text as `rsna-knee-wguesdon-baseline-v1.ipynb`). Kernel API current source is **V5** (T4, internet off, model `metaresearch/dinov2/PyTorch/small/1`).
- claimed_public: **0.802** (Kaggle listing: Public 0.802, Best 0.802 **V4**, T4×2, ~1h 11m). The notebook body does not print that number; treat it as the V4 scored run, not a V5 reprint.
- backbone / input:
  - Frozen **DINOv2 ViT-S/14** (patch 14, hidden 384, 12 blocks). Per slice: **CLS + patch mean + patch max** → 1152-d. ImageNet mean/std. Only `cuda:0` even if two GPUs show.
  - Corpus FOV is **150.0 mm** on every series. Native matrices: 960 / 896 / 800 / 640 px at **0.1562 / 0.1674 / 0.1875 / 0.2344 mm/px**.
  - Formula: `mm/px = 150 / input_px`; `mm/token = 150 * 14 / input_px`.
  - **126 px (public frontier):** 1.190 mm/px, **16.7 mm/token**, 9×9 = 81 tokens. A 1 mm tear is below one pixel. Nyquist for a 1 mm tear is ≤0.5 mm/px → **≥300 px**.
  - **336 px (this kernel):** 0.446 mm/px, **6.25 mm/token**, 24×24 = 576 tokens. Smallest multiple of 14 that clears 300 px with margin. Synthetic probe: 1–3 mm lesions move the pooled embedding ~2–5× farther than at 126; a 10 mm feature gains nothing.
  - **448 px:** probe **does not beat 336** on any tested lesion width. Ladder in code is `[336, 280, 224]` if the GPU clock blows; 448 is not used.
  - Slots are **5 contrast slots**, not 6 generic “second series in this plane”: Sagittal Fluid **12**, Sagittal Structural **12**, Coronal Fluid **8**, Coronal Structural **6**, Axial Fluid **8** = **46 slices** when full (~43/166 measured, ~26%; claimed fill **93%**). Axial non-fluid dropped (only ~19.4% of studies). Plane windows on geometry-ordered stacks: Sag/Ax **(0.12, 0.88)**, Cor **(0.20, 0.80)**. Order by **DICOM physical position**, not filename/SOP UID. Intensity: **per-series** percentile window (not per-slice).
- labels: official 12 (`Baker's` apostrophe). `LABEL_SOURCE=auto` prefers attached LLM soft labels `wguesdon/rsna-knee-llm-report-labels-opus`, then a rule file, then inline rules. Rows in `train.csv` with all 12 gold columns get **loss weight 8.0**. Reports are train-only.
- CV: frozen head is **5-fold**; per fold **truncated SVD 512** then RidgeCV (GCV alpha) on a **5 slots × 2 stats × 1152** pool. MLP head 256-d, 18 epochs, lr 2.5e-3, wd 1e-2, dropout 0.2, seeds 20260805/06/07, rank blend **0.5**. Fine-tune path: **one grouped holdout fold** (`FT_VAL_FOLD=0`); last **4** blocks open; 1 centre 2.5D image per slot (5 images/study, not 46); encoder lr 1e-5, head lr 2.5e-3, 8 epoch cap, study batch 4; rank-blend weight **0.45**. No published fold AUC table in the source cells.
- inference: **encode hidden test first**, never subsample (`TEST_ENCODE_BUDGET_S=9000`; train encode may subsample). Frozen 46-slice embeddings + optional rank-blend with the 5-slot fine-tune. If torch / pydicom / checkpoint / DICOMs fail, fall back to series-manifest metadata and still write `submission.csv`. Binding cost is DICOM decode, not FLOPs.
- copyable next step: **CPU-only (this contest rejects P100; keep `enable_gpu: false`).** Port `SLOT_SPEC` + `PLANE_WINDOW` + physical-position slice order + per-series window into the 0.526 metadata-ranker kernel as **slot-fill / plane-window / header features** (no DINOv2 forward). Do not encode 336² ViT-S on CPU.
- do not copy: the T4 336 px / 46-slice encode or the fine-tune path; any P100/`enable_gpu: true` run; 126 px DINOv2 (tears are gone after resize); 448 px (probe says no gain); 6 generic plane slots or filename slice order; per-slice intensity window; DataParallel on T4×2; assuming `train.csv` lives at `/kaggle/input/<slug>` only; subsampling test.
