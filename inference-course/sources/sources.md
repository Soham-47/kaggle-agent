# Sources

The course draws on three references. Every lesson is original prose
written for this course; no text is copied verbatim from any source.
Topics are attributed per day in `ROADMAP.md` with the short names below.

## Usage rules

1. Read a reference before writing a lesson that cites it.
2. Restate concepts in the lesson's own words.
3. Keep the attribution per day in `ROADMAP.md` accurate.
4. Never paste source text, images, or code into lessons.
